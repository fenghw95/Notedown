01

AI 打工人经济测试框架

港大最近开源了一个挺有意思的项目 ClawWork，把 AI Agent 放到真实的经济环境里去打工赚钱。

![Image](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU3rnDfo4uTccuWtlLHLOcOcdbAPgymGrmE9KXYO4T4XKko9DJOZLiclPGeIenFbFZ6ibpY313hIN8qXDpaWcTu56iaUPYQFibPLPII/640?wx_fmt=png&from=appmsg#imgIndex=0)

说白了就是让 AI 不是帮你干活，而是自己出去接单子挣钱。

每个 AI 代理只有 **10 美元**启动资金，每次调用 LLM 都要扣费，必须通过完成任务赚钱才能活下去。

项目涵盖了 **220 个真实职业任务**，覆盖 **44 个经济领域**，包括技术工程、商业金融、医疗社会服务这些。

支付系统是基于美国劳工统计局的时薪数据算的，单个任务价值从 **82 美元到 5000 美元**不等。

![Image](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU2vNNPKXFxp3X7Ns0G7Iiagj7zic6CgxRXDqUv7jlp8hSBOWicoLXjozGjDyMKLtgKSOARuVk5dr4SvYM2c181ibqpnO5B2ztheR88/640?wx_fmt=png#imgIndex=1)

顶级 Agent 可以实现 **每小时 1500 美元以上**的等效收入，已经超过一般白领的生产力了。项目还带一个实时 React 仪表盘，能看到余额变化、任务完成情况这些数据。

想要本地跑的话，克隆仓库之后创建个 Python 3.10 环境就行，启动脚本都写好了。

![Image](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU2cckGXmJgng6EBTLJKyniaKibwKtdowJBMhZS8Tdtjdmb4129emppLLJeuHpp5QjdT3qu0BjgAnxXnJaFU182fXJQPTNyl7cZYU/640?wx_fmt=png#imgIndex=2)

开源地址：https://github.com/HKUDS/ClawWork

给 AI Agent 装上互联网能力

Agent-Reach 这个项目解决了一个很实际的问题：让 AI Agent 能顺畅地访问各种互联网平台。

![Image](https://mmbiz.qpic.cn/mmbiz_png/M2ibDBMdECU2u3bkibibwS7A4BQn4Sao2jiaT2HvWiar36hL2qwpia4jkhvWDwKyZ6A8rqiaShrewiaauID3Co5NTib8sgAxqXDNGPOFL7icibWTFr72KE/640?wx_fmt=png&from=appmsg#imgIndex=3)

搞过这方面的人应该知道，Twitter API 要付费，Reddit 经常封 IP，小红书必须登录才能看，B 站从服务器访问会被屏蔽。

每个平台都要单独折腾一堆配置，这个项目把这些问题都打包解决了。

支持 **YouTube 字幕、Twitter 推文、Reddit 讨论、GitHub 仓库、B 站视频、小红书内容、RSS 源**这些，基本覆盖了主流平台。

安装也很简单，pip 一键安装就行，然后跑个 doctor 命令检查环境。底层工具都是精选的，读网页用 Jina Reader，读推特用 birdx，视频字幕用 yt-dlp，全网搜索用 Exa AI。

关键是 **完全免费**，Cookie 只存在本地不上传。每个渠道都是独立的 Python 文件，后端工具随时可以换。

开源地址：https://github.com/Panniantong/Agent-Reach

在 Obsidian 里直接用 Claude 的插件

如果你是 Obsidian 用户又经常用 Claude，这个插件能省不少事。

Obsidian 的 CEO 最近开源了一个 obsidian-skills 项目，**现在 1 万多 Star**。

它让 AI 能正确处理 Obsidian 的专属语法，比如双链、callouts 这些，不会把笔记格式搞乱。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_png/M2ibDBMdECU3ezZNOGGs4rY2PnqOIjeSFUDr1Y8qYOuLmqiaRjp9jukMgMicCkpDiaZtzSBmp1TCkW3PPloEicibKMbUNHoQP9JYjefDwKA4r3YYY/640?wx_fmt=png&from=appmsg#imgIndex=4)

配套的 Claudian 插件可以直接在 Obsidian 里和 Claude 交互，不用在不同应用之间切来切去。

AI 可以直接在你的知识库里工作，原地内联编辑，还完整支持 Claude Code 的 Skills 体系。

安装的话需要先装 Claude Code CLI，然后把插件文件复制到 Obsidian 的插件目录里启用就行。零外部依赖，完全本地友好。

说实话这个需求挺刚需的，之前 AI 经常把 Obsidian 的 wikilinks 语法搞坏，有了这个就不用担心了。

开源地址：https://github.com/kepano/obsidian-skills

开源的 AI 新闻摘要工具

ClawFeed 是一个开源的 AI 新闻摘要工具，口号是 **Stop scrolling, Start knowing**，挺形象的。

![Image](https://raw.githubusercontent.com/fenghw95/Notedown/main/notedown/assets/d/d1803796538562f0/327912f38e8c9b508c99507deba0925943d2ac34.jpg)

现在每天刷各种信息源花好多时间，但真正有价值的内容并不多。

这个工具能从 **Twitter、RSS、HackerNews、Reddit、GitHub Trending** 这些地方抓取内容，然后用 AI 帮你提炼出重点。

支持 **4 小时、每日、每周、每月**四种摘要频率，你可以根据自己的阅读习惯来选。比较有意思的是 **Source Packs** 功能，可以把精选的信息源打包分享给别人，社区成员一键安装就行。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M2ibDBMdECU189rNMx4VTJhYQibtQ92OPSxzFibwNgzhmSGpIyJV7IV6j49elgdyuDZJwQ5IhBPiccBaAlDx1w46kyXkP9tIZic1l1MgZffu9JLs/640?wx_fmt=jpeg#imgIndex=6)

还有个 **Mark & Deep Dive** 功能，看到感兴趣的内容标记一下，AI 会深度分析给你更详细的解读。输出支持 RSS、JSON Feed、HTML 多种格式。

部署方式挺灵活的，可以当 OpenClaw 技能装，也可以当 Zylos 技能用，独立部署也行。数据存在 SQLite 里，零配置。

开源地址：https://github.com/kevinho/clawfeed
